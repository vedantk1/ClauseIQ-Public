# Synthetic workspace demonstration

The JSON is authored fixture data, not provider output, legal advice or a quality
benchmark. It exercises the new review workspace before generation is connected.
Only the exact SHA-256 of tests/fixtures/pdfs/managed-services-25p.pdf is accepted;
the filename alone is never sufficient. No fixture is installed into a library
automatically. Loading the example is an explicit local action and spends no AI
tokens. Its fixed Example Customer context does not overwrite the person's brief.

Each evidence match must identify exactly one stored extraction span on the stated
physical PDF page. The server publishes that span's full exact text and ID, tied to
the stored source revision. Matching confirms wording/location, not completeness,
interpretation or legal effect. Invalid or ambiguous matches refuse the fixture.

Keep fixture changes synchronized with deterministic tests. Do not regenerate
PDFs or use real agreements to update this example. Personal drafts, questions,
markers and resume history belong in the local database, never this directory.
